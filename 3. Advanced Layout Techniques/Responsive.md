# Responsive website using HTML and CSS.

## Understanding Units
- `px`
- `%`
- `vw`, `vh`    View port Height/Width
- `vmax` , `vmin`   View port maximun/minimum
- `em` , `rem`

## Layout of website.
- absolute  vs  flex

## flex Box
- `display: flex`
- Aligning items in `X` and `Y` axis
- `flex: direction`
- justify-content
- align-item
- flex wrap
- gap

## CSS media queries
- `min height`,   `min width`
- `min width`,    `max width`

```css
@media (max-width: 600px) {
    /* CSS Responsive Code */
}
```
